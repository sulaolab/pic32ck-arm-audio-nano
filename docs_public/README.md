# Documentation

These guides cover the supported hardware, build, programming, and normal
operation of the PIC32CK ARM Audio Nano firmware.

- [BUILD.md](BUILD.md) describes the supported MPLAB X build and programming
  route.
- [IMPLEMENTATION.md](IMPLEMENTATION.md) explains the two DF2T implementations
  and the optional verification source retained by the project.
- [OPERATION.md](OPERATION.md) describes the audio connections, serial console,
  startup checks, and normal controls.
- [VALIDATION.md](VALIDATION.md) records the target hardware, audio format, and
  verified operating behaviour.
